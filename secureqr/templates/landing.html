Check a QR code before it checks you.

SecureQR decodes QR codes from photos or your webcam and tells you whether the link inside looks like phishing. It never opens the link.

Scan a QR code How it works

Three checks on every scan

Each layer is reported separately, so you can see exactly why a link was flagged.

1Decode

OpenCV reads the QR code, including coloured and dotted designs, and identifies what it holds: a link, UPI payment, Wi-Fi login, phone number or text.

2Classify

A Linear SVM built from {{ "{:,}".format(metrics.dataset.rows_deduplicated) if metrics.dataset else "500,000+" }} unique labelled URLs scores the link using character patterns and 30 lexical features.

3Explain

Security rules check for IP hosts, shorteners, look-alike domains, dangerous schemes and more, then combine with the model into a low, medium or high risk level.
